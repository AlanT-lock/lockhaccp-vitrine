- Lis tout le plan avant de modifier quoi que ce soit, puis traite les tâches ensemble : regroupe les changements par gabarit, composant ou fichier partagé (une correction à la source vaut mieux que page par page).

- Respecte les conventions du projet ; change le minimum nécessaire ; pas de refactorisation hors sujet.
- Ne modifie pas les URLs existantes, le design, ni le tracking / analytics non concerné.
- Commence par les corrections techniques, puis les rédactions.
- Rédactions : écris un contenu utile en t'appuyant uniquement sur les informations déjà présentes dans le dépôt (textes des autres pages, articles, fonctionnalités décrites, données du site). N'invente aucun fait : prix, chiffres, avis, témoignages, références clients, adresse, horaires, mentions légales. Ce qui manque reste absent : marque alors la tâche « partiel » et liste les informations à fournir.

- Si le projet a un script de build ou de lint, lance-le à la fin et corrige les erreurs que tu as causées.
